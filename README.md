# Deepfake Detection using CNN and GAN

## Project Overview
This project focuses on detecting AI-generated deepfake images and videos using Deep Learning techniques. The model analyzes facial features and visual artifacts to distinguish between authentic and manipulated content.

## Problem Statement
The rapid growth of AI-generated media has increased the risk of misinformation, identity manipulation, and digital fraud. This project aims to identify deepfake content using advanced deep learning techniques.

## Objective
To develop a system capable of detecting manipulated images and videos by analyzing facial inconsistencies and visual artifacts.
