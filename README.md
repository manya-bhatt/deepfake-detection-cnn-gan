Deepfake Detection using CNN and GAN
Project Overview

This project focuses on detecting AI-generated deepfake images and videos using Deep Learning techniques. The model analyzes facial features and visual artifacts to distinguish between authentic and manipulated content.

Technologies Used:
Python
TensorFlow
CNN (Convolutional Neural Networks)
GAN (Generative Adversarial Networks)
Google Colab


Features:
Deepfake image detection
Deep learning-based classification
Model training and evaluation
Image preprocessing and feature extraction


My Contribution:
Data preprocessing and preparation
Model development and training
Performance evaluation
Result analysis and testing


Outcome:
Successfully developed a deepfake detection model capable of identifying manipulated media with good classification accuracy.
