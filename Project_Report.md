# Deepfake Detection using CNN and GAN

## Problem Statement
The rapid growth of AI-generated media has increased the risk of misinformation and identity manipulation.

## Objective
To develop a system capable of identifying manipulated media content using deep learning techniques.

## Technologies Used
- Python
- TensorFlow
- CNN
- GAN
- Google Colab

## Methodology
1. Data Collection
2. Data Preprocessing
3. CNN Model Training
4. GAN-based Analysis
5. Testing and Evaluation

## Outcome
Successfully developed a deepfake detection model capable of distinguishing manipulated and authentic media.

## Future Scope
- Real-time detection
- Video analysis
- Improved accuracy with larger datasets
